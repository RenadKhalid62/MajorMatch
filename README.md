# MajorMatch
MajorMatch is a website designed to help students explore and compare computer majors in Computer Science, Information Technology, and Computer Engineering.

The website provides students with information about each major, its study plan, and interactive experiences that allow them to explore different fields and gain a better understanding of what each major involves.

## Features
- Explore different computer majors.
- View and compare study plans.
- Try interactive experiences related to each major.
- Take quizzes to explore interests and suitable fields.
- Compare majors to help make a more informed academic choice.

## Majors
- Computer Science.
- Information Technology.
- Computer Engineering.
